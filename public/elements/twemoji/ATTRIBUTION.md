The SVG graphics in this directory are a curated subset of **Twemoji v17.0.2** from the maintained [jdecked/twemoji](https://github.com/jdecked/twemoji) project.

- Graphics license: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
- Upstream graphics license text: [LICENSE-GRAPHICS](https://github.com/jdecked/twemoji/blob/v17.0.2/LICENSE-GRAPHICS)
- Source files: `https://github.com/jdecked/twemoji/tree/v17.0.2/assets/svg`

The graphics are stored locally so the editor and exported designs do not depend on a runtime CDN. Attribution belongs in project legal/about documentation and is not drawn onto customer cake-topper exports.
